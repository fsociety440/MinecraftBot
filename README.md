# 🤖 Minecraft Telegram Manager Bot

Этот проект представляет собой мощную систему для управления ботами в Minecraft напрямую из **Telegram**. Бот идеально подходит для автоматизации рутины на анархии или выживании, фарминга, разведки и просто контроля аккаунтов с телефона, когда вас нет за ПК.

## ✨ Главные возможности

* **📱 Полное управление через Telegram:** Добавление, удаление, подключение и отключение ботов через удобное меню.
* **👥 Мультиаккаунтность:** Управляйте неограниченным количеством ботов одновременно из одного чата.
* **🚨 Радар и Анти-Гриф (Паника):** Бот сканирует зону прорисовки. Если появляется чужой игрок (не из вайт-листа), бот моментально выходит с сервера для сохранения вещей и присылает экстренное уведомление в Telegram.
* **🛡 Вайт-лист и система "Хозяин":** Настройте список доверенных игроков, от которых бот не будет убегать. Назначьте Хозяина, чтобы бот слушался его команд через личные сообщения прямо в игре.
* **⚔️ Боевые и фарм-макросы:**
  * **Авто-атака (Фарм):** Бот бьет мобов и игроков вокруг себя.
  * **Авто-еда:** Возможность приказать боту взять еду в левую руку (`возьми еду`), чтобы он мог одновременно бить и есть.
* **🖼 Поддержка GUI-меню (Капчи, Выбор режимов):** Бот перехватывает открытые в игре меню и отправляет их в Telegram в виде кликабельных кнопок. Позволяет легко проходить капчи и заходить на режимы с телефона!
* **📊 Глобальный мониторинг:** Закрепленное сообщение в Telegram, которое обновляется в реальном времени и показывает здоровье (ХП) и сытость всех ваших онлайн-ботов.
* **🎒 Управление инвентарем и слотами:** Выбор активного слота в панели быстрого доступа через ТГ.
* **👁 Направление взгляда:** Возможность повернуть бота в нужное направление (используя строку Facing из F3).

## 🚀 Установка и запуск

### 1. Требования
* Установленный [Node.js](https://nodejs.org/) (версии 18 и выше)
* Токен Telegram-бота (получить у [@BotFather](https://t.me/botfather) в Telegram)
* Ваш Telegram Chat ID (можно узнать через ботов вроде [@userinfobot](https://t.me/userinfobot))

### 2. Клонирование и зависимости
Склонируйте репозиторий и установите библиотеки:
```bash
git clone https://github.com/fsociety440/MinecraftBot.git
cd MinecraftBot
npm install
```

### 3. Настройка окружения
В корневой папке проекта создайте файл `.env` и впишите в него ваши данные:
```env
TG_TOKEN=ваш_токен_от_ботфазера
TG_CHAT_ID=ваш_личный_chat_id
```

### 4. Запуск бота
```bash
node index.js
```

## 🕹 Как пользоваться
1. Запустите скрипт `node index.js`.
2. Перейдите в вашего бота в Telegram и отправьте команду `/menu`.
3. Появится главное меню, где вы сможете добавить своего первого Minecraft-бота, указав его никнейм.
4. Настройте "Хозяина" и Вайт-лист в меню **⚙️ Настройки**.
5. Нажмите **"Подключиться"** для входа на сервер.

## 💬 Команды для ЛС (в Minecraft)
Если вы настроили ник Хозяина, вы можете писать боту в ЛС прямо в игре:
* `иди ко мне` — Бот попытается пойти к вам (если видит вас).
* `иди ко мне [X] [Y] [Z]` — Если бот вас не видит, укажите свои координаты, и он отправится на них.
* `возьми еду` — Бот найдет еду в инвентаре, возьмет её в левую руку и продолжит свои дела.

## 🛠 Технологии
* `mineflayer` — мощный API для создания ботов Minecraft.
* `node-telegram-bot-api` — работа с Telegram API.
* `mineflayer-pathfinder` — поиск пути и перемещение бота по миру.
